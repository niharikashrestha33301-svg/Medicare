Setup & notification troubleshooting

Use HTTPS or localhost in a supported browser. Open site permissions to allow notifications; also check your operating system?s notification settings. On supported iPhone/iPad devices, add MediCare to the Home Screen first.

If push is not configured, the administrator should run npm.cmd --prefix backend run setup:medicine and restart only the Node API. Keep VAPID keys stable. Configure a real VAPID contact for production.

Email requires SMTP_HOST, SMTP_PORT, SMTP_FROM and the service?s credentials in backend/.env. After the API restarts, verify your account email here. Never enter SMTP credentials into this patient page.

To check closed-page delivery, enable reminders, schedule the 60-second test, close all MediCare windows, and reopen this page later. Only a browser-reported display receipt can establish that the service worker ran with no site windows open.

Web Push can work when the page is closed on supported browsers. The MediCare server, internet connection, and browser/OS notifications must remain available. Delivery may be delayed or blocked by battery settings. On supported iPhones and iPads, add this page to the Home Screen first. This is not a guaranteed medical alarm.

Reminders continue on this device after signing out until you disable them here or in browser settings. Avoid enabling them on shared devices.
